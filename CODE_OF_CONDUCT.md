# Code of conduct

Everyone participating in this project — in issues, pull requests, discussions and reviews — is expected to:

- Be respectful and considerate. Disagree with ideas, not people.
- Assume good faith, and ask before judging.
- Keep feedback specific and actionable, and accept it in the same spirit.
- Respect privacy: don't post others' personal information, and don't paste private code or data into public threads.

Harassment, discrimination, personal attacks, and sustained disruption are not tolerated. Maintainers may edit, remove or lock content that breaks these rules and may block repeat offenders.

To report a problem, contact the maintainers through GitHub's private vulnerability reporting form on this repository (it reaches the maintainers privately even for non-security matters) or by opening an issue marked "conduct" if you are comfortable doing so publicly. Reports are handled confidentially.
